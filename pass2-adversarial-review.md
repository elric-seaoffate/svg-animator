## 8. Scene Synchronization and Snapshot Analysis (Including Adversarial Scenarios A–J)

### 8.1 Asymmetric Snapshot Pipeline Summary
1. **`JS → Go` (`render() → syncScene()`):** Triggered on every visual redraw (`app.js:7347`), Undo/Redo (`history.js:388`), New Project (`projects.js:651`), and Project Load (`projects.js:269`). Replaces Go `activeScene` via `SetFromSnapshot`, wiping `s.background = nil`, stripping Stage 8–15 crop/clip/custom-icon/visibility/lock/metadata fields, coercing `0` camera/optical values via `||`, and overwriting `s.revision` with `Date.now()`.
2. **`Go → JS` (`syncFromEngineSnapshot()`):** Triggered by `Group.Move` (`engine-bridge.js:1236`), `Scene.Paste` (`L1294`), and `Scene.Duplicate` (`L1313`). Pulls Go's stripped snapshot back into JS modules, wiping Node labels/colors/animations, Ripple rings, Flow routes/custom icons, Image crops/clips, and unhiding/unlocking every layer via `LayerManager.setLayers` (`L1224`).
